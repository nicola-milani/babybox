# Audio

Gli MP3 **non** vanno su git (sono pesanti e personali): stanno sulla microSD e in un backup a parte. Qui restano solo le regole e i suoni di sistema.

## Regole per chi registra
- Ambiente silenzioso, telefono o microfono USB a 20–30 cm dalla bocca; montaggio con Audacity.
- Esportazione MP3 mono, 44,1 kHz, 96 kbps (circa 0,7 MB al minuto).
- Normalizzare tutte le tracce a **−16 LUFS**.
- Una cartella per storia, file numerati: `01 - inizio.mp3`, `02 - il bosco.mp3`.

## Struttura sulla microSD
```
/storie/<titolo storia>/01 - ....mp3
/musica/<titolo canzone>/<file>.mp3|m4a
/sistema/   (suoni di sistema)
/nanna/     (messaggi di blocco)
```
