# Task 4 · Registrazioni e suoni di sistema

Vedi `audio/README.md` per le regole di registrazione.

Suoni di sistema in italiano: avvio, carta sconosciuta, batteria scarica,
WiFi attivo, spegnimento, **modalità configurazione**.

Il file della modalità configurazione si chiama
`/sistema/modalita-configurazione.mp3` e lo riproduce il box quando si tiene
premuto il tasto genitori sul fondo: senza display è l'unico modo di sapere
che la rete del box si è aperta. Basta una frase: «Rete del box aperta,
collega il telefono».

> **«Batteria scarica» non è più facoltativo.** Tolto il display (task 2
> annullato), è l'unico modo che il box ha di dirlo da solo: ESPuino sa
> riprodurre un file dalla SD quando la tensione scende, interrompendo
> l'ascolto e riprendendo dallo stesso punto. Va registrato e la funzione va
> accesa dalla web UI (Generale → Batteria).
